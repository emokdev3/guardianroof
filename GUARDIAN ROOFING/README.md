# Guardian Roofing Website Scaffold

A simple static website scaffold for Guardian Roofing, built with HTML, CSS, and JavaScript.

## Files

- `index.html` — landing page layout with hero, products, gallery, services, locations, contact, and footer.
- `styles.css` — brand styling using Guardian Roofing red, yellow, white, and charcoal.
- `script.js` — mobile nav toggle, gallery filters, lightbox preview, and hero carousel.

## Usage

1. Open `index.html` in your browser.
2. Replace placeholder gallery visuals with real project photos.
3. Hook the contact form to your backend or email service if needed.
